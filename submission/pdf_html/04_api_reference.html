API Reference

OpenAPI 3.0 specification summary — all endpoints, schemas, and response codes
Base URL: http://localhost:8080 Auth: JWT Bearer Token Spec file: openapi.yaml (importable into Swagger Editor & Postman)
The full machine-readable spec is in openapi.yaml. Import it into Swagger Editor (editor.swagger.io → File → Import File) for interactive documentation, or into Postman (Import → select file) to generate a ready-to-use request collection.

Authentication

All endpoints except POST /api/auth/login require a JWT Bearer token in the Authorization header:

Authorization: Bearer <token>

Tokens are issued on login and expire after 24 hours.

Error Response Format

All error responses follow the same structure:

{
  "status":  400,
  "error":   "Bad Request",
  "message": "Payroll already exists for this employee in September 2026",
  "path":    "/api/payroll/generate"
}

Viewing the Full Spec

The openapi.yaml file in the submission/ folder is a complete OpenAPI 3.0.3 specification. To view it interactively:

Option A — Swagger Editor (no install)

  1. Open a browser and go to editor.swagger.io
  2. Click File → Import File
  3. Select submission/openapi.yaml
  4. The right panel shows the full interactive documentation
  5. You can try requests directly from the browser (requires CORS-enabled backend)

Option B — Postman

  1. Open Postman → click Import (top-left)
  2. Select submission/openapi.yaml
  3. Postman generates a full collection from the spec
  4. Set the base URL and JWT token in the collection variables
